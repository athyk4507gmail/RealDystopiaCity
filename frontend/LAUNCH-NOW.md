## ⚡ Quick Launch (11 minutes)

### Step 1: Create OG Image (5 min)

**Option A: Screenshot Method (Easiest)**
```bash
npm run open:og-template
```
Then take a screenshot at 1200x630px and save to `public/og-image.png`

**Option B: Automatic (requires canvas)**
```bash
npm install canvas
npm run generate:og
```

### Step 2: Verify Build (3 min)

```bash
# Type check

# Build
npm run build

# Test locally
```
