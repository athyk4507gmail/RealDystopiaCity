## 🚀 Quick Deploy

### Option 1: One-Command Deploy (Vercel)

```bash
npm run deploy:vercel
```

That's it! Your site will be live in ~2 minutes.

### Option 2: Using Deploy Script

```bash
npm run deploy
```

Interactive menu will guide you through:
1. Pre-flight checks
2. Build verification
3. Deployment method selection

### Option 3: Manual Deploy

```bash
# Build
npm run build

# Test locally
npm start

# Deploy to Vercel
vercel --prod
```
