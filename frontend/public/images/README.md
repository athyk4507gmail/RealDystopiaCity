# Image Assets

## Water Globe Illustration

**Required:** Save the uploaded water-themed illustration (globe with tap) as:
`water-globe-illustration.png`

This image is used as a subtle decorative background element on the Water Distribution page.

**Steps to add the image:**
1. Save your uploaded JPG image
2. Convert it to PNG format (optional but recommended for better blend modes)
3. Save it as `water-globe-illustration.png` in this directory

The image will appear as a low-opacity decorative element in the bottom-right corner of the Water Distribution page.
