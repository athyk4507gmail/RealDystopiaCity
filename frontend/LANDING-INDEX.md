## 🛠️ Deployment Tools

### Scripts
- **deploy.sh** - Automated deployment with pre-flight checks
- **generate-og-image.js** - Node canvas OG image generator
- **og-image-template.html** - HTML template for screenshot method

### Package.json Commands
```bash
npm run dev              # Development server
npm run build            # Production build
npm run deploy           # Interactive deploy
npm run deploy:vercel    # Direct Vercel deploy
npm run generate:og      # Generate OG image
npm run open:og-template # Open OG template
```
