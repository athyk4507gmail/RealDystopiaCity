## 🎨 Design System

### Colors
| Token | Value | Usage |
|-------|-------|-------|
| Black | `#000000` | Backgrounds |
| White | `#ffffff` | Primary text |
| Teal | `rgba(94, 234, 212, *)` | Accents, glows |
| White/65% | `rgba(255, 255, 255, 0.65)` | Secondary text |
| White/40% | `rgba(255, 255, 255, 0.4)` | Muted text |

### Glass Treatment
```css
background: rgba(255, 255, 255, 0.04-0.08);
backdrop-filter: blur(14-16px) saturate(160-180%);
border: 1px solid rgba(255, 255, 255, 0.1-0.15);
border-radius: 14-20px;
```

### Shadows (3-Layer System)
```css
box-shadow:
  0 1px 0 rgba(255, 255, 255, 0.06) inset, /* highlight */
  0 -1px 2px rgba(0, 0, 0, 0.3) inset,      /* depth */
  0 12px 30px rgba(0, 0, 0, 0.35);          /* ambient */
```

## 🎓 Key Learnings

### Design Patterns Used
1. **Glassmorphism**: Premium semi-transparent cards
2. **Staggered animations**: Cinematic entrance effects
3. **Wave animations**: Gentle floating movements
4. **Hover orchestration**: Multiple elements animate together
5. **Responsive grids**: Mobile-first layouts

### CSS Techniques
1. **Backdrop blur**: `backdrop-filter: blur(14px)`
2. **3D transforms**: `perspective: 1000px` + `rotateY()`
3. **Gradient borders**: Dual-layer backgrounds
4. **Inset highlights**: 3-layer shadow system
5. **Cubic bezier**: `cubic-bezier(0.2, 0.8, 0.2, 1)`

### Performance Tricks
1. **GPU layers**: `transform: translateZ(0)`
2. **Animation pausing**: `animation-play-state: paused`
3. **Will-change**: Only on hover states
4. **Contain**: Isolate repaints
5. **Contents display**: Subgrid behavior
